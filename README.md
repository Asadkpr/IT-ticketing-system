# IT-ticketing-system

An enterprise IT Ticketing and Support Management System built with React, Vite, Firebase (Auth & Firestore), and Tailwind CSS.

## Features
- **Ticket Management:** Create, assign, prioritize, track, resolve, and close tickets.
- **Role-Based Access Control:** Role hierarchy with Admin, IT Members, and Standard Users.
- **Department Chat Groups & Direct Messaging:** Real-time chat with department groups, public channel, and private messaging.
- **User Management & Password Reset:** Admin portal to add users (with custom department support), manage permissions, and reset credentials.
- **Offline / Local Fallback:** Resilient local storage fallback and self-healing data synchronization.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

The application runs locally on `http://localhost:3000`.
